Los skins se cargan automáticamente mediante listas dinámicas del tema.

Se recomienda usar nombres de carpeta simples:
- Sin espacios
- Sin signos especiales
- Usar nombres simples (ej. "default", "minimal", "neon")

Si deseas agregar una descripción más detallada para el skin, utiliza el archivo `info.ini`.
